# Implementation Paper

`opspilot_plus_implementation.tex` -- IEEE conference-format (IEEEtran)
implementation paper, compiles cleanly with `pdflatex` (two passes for
cross-references). `opspilot_plus_implementation.pdf` is the compiled output
included for convenience; regenerate it with:

```bash
pdflatex opspilot_plus_implementation.tex
pdflatex opspilot_plus_implementation.tex   # second pass resolves references
```

Requires the `IEEEtran` class (in TeX Live, install via the
`texlive-publishers` package if missing) and a standard LaTeX distribution
with `tikz`, `booktabs`, and `amsmath`. Figures referenced by the paper live
in `figures/` and are the same plots in `../docs/results/`, generated by the
evaluation harnesses described in `../docs/EVALUATION_RESULTS.md`.

Every number, table, and figure in this paper comes directly from
`../docs/EVALUATION_RESULTS.md` and the evaluation runs described there --
nothing here was hand-adjusted independently of that document.
